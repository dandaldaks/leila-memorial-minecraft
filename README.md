# Leila Memorial - Minecraft Java

Server-side datapack + resource-pack scaffold for Leila's memorial.

## Commands

- `function leila:play`
- `function leila:stop`
- `function leila:funeral`

The resource pack expects the custom sound event `leila:neverender`.

## Server setup

Put the datapack in `<world>/datapacks/`, run `/reload`, and configure your server resource-pack URL in `server.properties`.

The commercial recording itself is intentionally not published in this public repository. Add an audio file you have the right to distribute at `resource-pack/assets/leila/sounds/neverender.ogg`, then build/host the resource-pack ZIP from a location you control.
